A Full-Stack Social Media & Real-Time Chat Platform built using the **MERN Stack** (MongoDB, Express, React, Node.js). Features include secure JWT authentication, rich media uploads, custom Dark/Light mode theme, and an interactive real-time messaging interface optimized for all screen sizes.

## ✨ Features

- **🔐 Authentication & Security:** User registration, login, logout, and protected routes using JWT & HTTP-Only cookies.
- **💬 Real-Time Messaging & Inbox:** Dynamic responsive chat interface with message history, deletion, and file/media support.
- **🌙 Dynamic Theme Toggle:** Seamless Light & Dark Mode switching across all views.
- **📱 Responsive UI Design:** Handled dynamic viewport height (`100dvh`) for mobile browser keyboard compatibility without UI clipping.
- **📝 Post Management:** Create posts with text, images, videos, and audio clips.
- **🖼️ Media Handling:** Fast cloud uploads for audio, video, and profile images powered by Cloudinary.
- **❤️ Social Interactions:** Follow/Unfollow users, live user search with auto-complete, and customizable user profiles.

## 🛠️ Tech Stack

### Frontend
- **React.js** (Hooks, Context/State, Router)
- **Axios** (API Requests)
- **CSS3** (Flexbox, Dynamic Variables, Custom Animations)
- **Lucide / React Icons**

### Backend
- **Node.js** & **Express.js**
- **MongoDB** & **Mongoose ORM**
- **JWT (JSON Web Tokens)** & **Bcrypt** (Security & Hashing)
- **Multer** & **Cloudinary** (Media Storage)
- **Cookie-Parser** & **CORS**
